# Jewel Bingo Bot — START HERE (Mac + Windows)

Repo: https://github.com/obanvalservices-oss/BingoMU

Do **not** install on the Windows game PC or local server.

---

## Sync con GitHub (recomendado)

### Primera vez (Mac o Windows)
```bash
git clone https://github.com/obanvalservices-oss/BingoMU.git
cd BingoMU
```

### Actualizaciones
```bash
cd BingoMU
git pull
```

La calibración (`assets/calibration/default.json`) es local y no se sube al repo.

| L | Jewel of Life |

```
S  - H  - B  - L  - H
CR - C  - C  - L  - C
B  - H  - MU - S  - C
B  - CR - CR - B  - L
```

## macOS

### Si sale “Apple could not verify… malware”
```bash
cd ~/Desktop/BingoMU   # o la carpeta donde clonaste
xattr -cr .
chmod +x *.command install_mac.sh
./1-Instalar.command
```

O: clic derecho → **Open** → **Open**.

1. `./1-Instalar.command`
2. Permissions: System Settings → Privacy & Security
   - Screen Recording → Terminal / Python
   - Accessibility → Terminal / Python
3. Open Chrome Remote Desktop → Jewel Bingo (window fixed)
4. `./2-Calibrar.command` — click panel + controls + 6 jewels (+/- = zoom)
5. `./3-Simular.command` — offline test
6. `./4-Play-Template.command` — LIVE with ChatGPT pattern
7. Optional: `./5-Play-Auto.command` / `./6-DryRun.command`
8. **Ctrl+C** or **Esc** = stop

## Windows (bot PC / Remote Desktop client — not the game PC)

3. `2-Calibrate.bat`
4. `3-Simulate.bat`
5. `4-Play-Template.bat`

## Tips

- Recalibrate if you move/resize the Remote Desktop window.
- TEMPLATE places 4 of each jewel manually (select jewel → click cells).
- AUTO uses the in-game Auto-Place button.
