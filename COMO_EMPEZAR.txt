## macOS

### Si sale “Apple could not verify… malware”
macOS bloquea archivos traídos de Windows/Drive. Haz **UNA** de estas:

**A) Más fácil**
1. Clic derecho en `1-Instalar.command` → **Open** → **Open**
2. Repite Open en los demás `.command` la primera vez

**B) Quitar el bloqueo de toda la carpeta (Terminal)**
```bash
cd ~/Desktop/JewelBingo
xattr -cr .
chmod +x *.command install_mac.sh
./1-Instalar.command
```

**C) System Settings → Privacy & Security** → abajo “Open Anyway” / “Abrir de todos modos”

---

1. Double-click **`1-Instalar.command`** (o usa B arriba)
2. Permissions: System Settings → Privacy & Security
   - Screen Recording → Terminal / Python
   - Accessibility → Terminal / Python
3. Open Chrome Remote Desktop → Jewel Bingo (window fixed)
4. **`2-Calibrar.command`** — click panel + controls + 6 jewels
5. **`3-Simular.command`** — offline strategy test
6. **`4-Play-Template.command`** — LIVE with ChatGPT pattern
7. Optional: **`5-Play-Auto.command`** / **`6-DryRun.command`**
8. **F8** = stop
